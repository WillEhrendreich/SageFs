WHY THIS FILE EXISTS
  SageFs reads FSI's emitted topology back through reflection and has to answer
  "is this path segment FSI's submission wrapper?". The compiler has an exact
  rule for that; SageFs used to have three different string heuristics. The
  excerpts below are the upstream rules SageFs.Core/FsiNaming.fs MIRRORS, quoted
  verbatim so the mirror is reviewable and so FsiNamingContractTests can pin the
  mirror against the text rather than against a comment someone might edit.

  Only the PREFIX CONSTANT is referenced live, out of the FSharp.Compiler.Service
  package SageFs.Core already depends on
  (FSharp.Compiler.Syntax.PrettyNaming.FsiDynamicModulePrefix, public in
  PrettyNaming.fsi). Nothing here is compiled; nothing is bulk-copied.

REFRESH PROCEDURE
  Re-clone/pull dotnet/fsharp, re-extract the excerpts below at their new line
  numbers, update COMMIT above, and re-run FsiNamingContractTests. If an excerpt
  changed meaning, FsiNaming.fs changes with it — never the other way around.

/// Try to take the "FSI_NNN" prefix off a namespace path
let TryStripPrefixPath (g: TcGlobals) (enclosingNamespacePath: Ident list) =
    match enclosingNamespacePath with
    | p :: rest when
        g.isInteractive &&
        not (isNil rest) &&
        p.idText.StartsWithOrdinal FsiDynamicModulePrefix &&
        p.idText[FsiDynamicModulePrefix.Length..] |> String.forall Char.IsDigit
        -> Some(p, rest)
    | _ -> None
--- END EXCERPT segment-predicate ---
