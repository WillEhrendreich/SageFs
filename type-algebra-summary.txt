## 3. TYPE HIERARCHY & CONNECTIONS

### Action Flow
  EditorAction
    ↓ (processed by)
  EditorState.update
    ↓ (produces)
  EditorEffect list
    ↓ (interpreted as)
  SageFsEvent
    ↓ (triggers state change)
  ElmLoop update

### Error Flow
  All operations return: Result<'T, SageFsError>
  SageFsError has classification:
    - isClientError (4xx - bad request)
    - isServerError (5xx - internal failure)
    - isGatewayError (502/504 - worker unreachable)
    - isInfraError (409 - system conflict)
  Mapped to HTTP status codes via toHttpStatus

### Session Lifecycle
  SessionState (capability model):
    Uninitialized → WarmingUp → Ready → Evaluating ↔ Ready
                                    ↘ Faulted
  SessionStatus (internal detail):
    Starting → Ready → Evaluating/Building ↔ Ready
                ↘ Faulted / Restarting ↘ Stopped
  SessionDisplayStatus (UI):
    Running, Starting, Errored, Suspended, Stale, Restarting

### Test Execution Phases
  RunPolicy (policy per category) → RunTrigger (what fired) → TestRunStatus (UI state)
  TestRunPhase (generation tracking):
    Idle ↔ Running(gen) or RunningButEdited(gen)
  ResultFreshness classifies results: Fresh | StaleCodeEdited | StaleWrongGeneration

### Live Testing State Machine
  LiveTestingActivation.Active/Inactive
    ↓
  TestRunPhase (generation-based)
    ↓
  TestRunStatus per test
    ↓
  GutterIcon for rendering

### UiDensity Cycling
  Minimal → Normal → Full → Minimal

## Summary: The Type Algebra

SageFs uses a **pure algebraic** type system:

1. **Actions** (EditorAction, UiAction) → immutable user intent
2. **Effects** (EditorEffect, SageFsEvent) → side-effect descriptions
3. **State** (EditorState, SessionState, LiveTestState) → immutable snapshots
4. **Errors** (SageFsError) → unified result type with classification
5. **Events** (SageFsEvent) → domain events for state transitions

**Message Flow**:
  User Input → EditorAction → EditorEffect → SageFsEvent → State Update → Render

**Error Flow**:
  Any operation: Result<'T, SageFsError>
  Classification: isClientError | isServerError | isGatewayError | isInfraError
  HTTP mapping: toHttpStatus

**Session Lifecycle**:
  Three-level abstraction:
    - SessionState (capability model)
    - SessionStatus (worker state)
    - SessionDisplayStatus (UI model)

**Test Execution**:
  RunPolicy × RunTrigger → TestRunStatus → GutterIcon
  Generation-based phase tracking prevents race conditions
